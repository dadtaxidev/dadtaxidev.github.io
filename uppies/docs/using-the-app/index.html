Handbook

Using the App

Every screen in Uppies, in the order you'll meet them — from first launch to backing up months of training.

First run: the setup guide

The first time you open Uppies, a short setup guide walks you through everything the program needs. Nothing in it is final — every choice can be changed later in Settings.

  • Profile name. Optional, but worth setting if two people will share the device. Leave it blank to stay "Me".
  • Units. Pounds or kilograms. Switching converts the profile's weights and rounding values for you, so it's safe to change your mind later.
  • Starting weights. For each of the ten lifts you can tap the checkbox to accept the suggested weight, or open the lift to enter a weight directly or estimate one from a recent hard set (you enter the weight and reps; Uppies works back through an estimated 1RM to a deliberately conservative starting point).
Good to know

The guide is resumable. Tap Skip at any point and the unreviewed lifts simply use their suggested values — a "Review starting weights" card appears on the Workout screen, and Settings → Finish setup guide reopens the walkthrough right where it matters. Not sure what to pick? Start lighter than your ego suggests; the program catches up fast.

The Workout screen

The Workout tab shows one session at a time, with one card per lift. Each card has the lift's name, an info button for its movement guide, and the working weight for today in the header.

Set rows

Below the header, each prescribed set gets its own row — warm-up sets first (for bench, overhead press, squat, and deadlift), then the working sets — each with a checkbox. Check a set off as you finish it. Main lifts prescribe two straight sets of 5 and a final "5+" set; the deadlift is the exception with a single "5+" working set; accessories prescribe two sets of 12 and a final "12+".

The reps stepper

The final working set is an AMRAP — as many reps as you can with good form. Enter what you got with the Reps on last set stepper. The minus and plus buttons step the count, and it starts as a dash, not zero: "no entry" and "zero reps" mean different things in Uppies. Long-press the stepper to clear an entry entirely.

Draft vs. confirmed — the one concept worth learning

Reps you enter are a draft until you check the final set's checkbox. Only a confirmed final set counts as a result, and only then does progression read it.

Concretely: say your bench is at 100 lb with a 5-rep target. You grind out 7 reps and tap the stepper up to 7. At this point nothing has changed — the outcome row stays blank and next session's bench is still whatever it was. Check the final set's box and it becomes official: the card shows Target Met and the next bench weight becomes 102.5 lb. Realize you miscounted and change the 7 to a 6? The checkbox clears itself, the result goes back to being a draft, and you confirm again when you're sure.

The checkbox on the final set stays disabled until you've entered reps — you can't confirm a result that doesn't exist yet.

Accessories work slightly differently — a ±2-rep band around the target holds the weight steady. The full rules live in The program.

A blue Next working weight line on every card always shows what that lift is prescribed at its next occurrence — met, missed, or still unlogged.

Volume and rep totals

Each card ends with a Loaded volume and Total reps row, and the bottom of the session sums them across every lift. Both count only sets you've actually checked off, and they finalize when you confirm the exercise's last working set — until then the card shows dashes. Totals are captured at completion, so a settings tweak next month won't quietly rewrite what you lifted today. Unloaded bodyweight sets (chin-ups or ab rollouts with no added weight) contribute reps but no loaded volume.

Rest timers

Checking off a warm-up or working set starts a rest countdown in the bar at the top of the Workout screen — except the last set of an exercise, because you're done with that lift, not resting for it. Warm-ups and working sets have separate durations: 1:00 and 4:00 by default, each adjustable from 0:30 to 5:00 in Settings → Rest timer.

  • While a timer runs, +15s and −15s buttons nudge it, and the ring around the start/stop button drains as rest elapses.
  • When time is up the bar shows Rest over and stays put until you dismiss it or check off another set — no vanishing message to miss mid-conversation.
  • Turn on Notify when rest ends to get a notification even if you've switched apps or locked the phone. It's off by default and asks for notification permission when enabled.
  • Don't want timers at all? The Rest timer toggle removes the bar entirely.

Navigating sessions and editing history

The chevrons in the toolbar move one session back or forward, and the Next session button at the bottom of the workout does the same as the forward chevron. On iPhone, tap the Week 2, Day 1 title to open History — a week-by-week list of every session so far, with a one-line summary of what you logged (like "Bench 102.5×5 · Row 52.5×6"), its totals, a green checkmark when complete, and the date. On an iPad in full screen, History lives in an always-visible sidebar instead. Tap any row to jump there.

If you try to advance past a session that still has unlogged lifts, Uppies asks first: Advance incomplete session?. That's because an unlogged lift projects its weight forward as if it went fine — advancing anyway is allowed, but it can raise future prescriptions for work you never did.

Editing a past session

Any old session can be corrected: navigate to it, fix the reps, and re-confirm the final set. Because every weight is recomputed from the log, fixing a three-week-old typo correctly rewrites every later occurrence of that lift. When an edit actually changes an upcoming weight, the card shows an orange caption so the change never happens silently — for example Rewrote next Bench: 102.5 lb → 105 lb — right under the blue next-weight line, which already shows the new value.

Profiles and Workout Together

Profiles let several people train on one device with completely separate settings, history, progress, and preferences. Manage them from Settings → Profile → Manage Profiles: create with New Profile, and rename, export, or delete from each row's menu. Deleting removes that profile's settings and training history for good, and the last remaining profile can't be deleted. A brand-new profile is offered its own starting-weight setup.

Switch profiles from that same Settings picker, or from the profile menu in the Workout screen's toolbar.

Workout Together

Training with someone at the same time? Open the profile menu on the Workout screen and choose Workout Together… (with only one profile on the device you'll see Add a Partner… instead). Pick a partner and tap Start. A participant bar appears above the session; tap a name to switch whose workout is on screen. Each name shows that lifter's own rest countdown — "Sam · 1:23" or "Sam · Ready" — because each participant keeps an independent timer, along with their own session, weights, history, and totals. Nothing is ever mixed. Tap the X in the bar (or End Workout Together in the menu) when you're done.

The Progress tab

Progress has two views, switched at the top.

Overview

Overview shows whole-program numbers: cards for all-time volume, total reps, completed sessions, and the latest session's volume, plus Volume by session and Reps by session bar charts. Like the in-workout totals, these count only confirmed work — a session you half-logged and abandoned doesn't inflate your history.

By Lift

By Lift focuses on one of the six main lifts (accessories aren't charted — they hold weight by design, so their trend line would just be flat). You get summary cards and two charts: Working weight over time, and Estimated 1RM computed from each confirmed AMRAP set using the Brzycki formula. Estimates from sets above 12 reps are drawn as larger orange points — the formula loses accuracy up there, so treat those as rough. A note below the chart explains the orange points whenever any appear.

Plate calculator and movement guides

Tap any set row on a barbell lift and Uppies shows exactly how to load the bar: the total weight, the bar itself, and each plate denomination with a per-side count. If the prescribed weight can't be built from standard plates, the leftover is called out rather than rounded away. The calculator uses your configured bar weight, and appears for the six bar lifts — bench, overhead press, squat, deadlift, row, and shrug. Chin-ups, ab rollouts, and the arm accessories don't load a full-size bar, so they don't get one.

The info button next to each lift's name opens its movement guide: Setup, Movement cues, Watch for (common mistakes), and A completed rep — what actually counts as a rep — plus a safety note where one matters.

Backups

Uppies stores everything on your device — there's no account and no cloud copy — so backup files are your safety net. There are three flows, and each covers a different job.

The active profile

Settings → Data → Export backup… saves a single JSON file containing the active profile's settings, complete training log, and current session; save it to Files, iCloud Drive, or anywhere else you keep things that matter. Import backup… restores one. It replaces the active profile's current program, so Uppies confirms — Replace current program? — before it reads the file.

Any profile, without replacing anything

In Settings → Profile → Manage Profiles, each profile row's menu has Export…, which produces the same kind of single-profile file without switching to that profile first. The Import Profile button there goes the other direction: it brings a single-profile file in as a new profile — it never replaces an existing one. You're asked to give the imported profile a name, and the name must be unique; the dialog won't proceed until a name collision is resolved. This is the way to copy one lifter's data to another device, or to restore a profile alongside the ones already on the phone.

The whole device

Settings → Data → Export full backup… writes one file containing every profile on the device. Import full backup… restores it — and because restoring replaces all profiles on the device, Uppies shows an explicit warning first, with the option to abort before anything is touched.

Hand any of these importers the wrong kind of file and nothing is harmed: the import fails with a clear message telling you which flow that file belongs to.

Careful

Export before deleting the app, before moving to a new phone, and ideally every few weeks — a full backup captures every profile in one file. And note that Reset all progress clears the profile's logged reps (its settings survive) — export first if there's any chance you'll want that history back.

The widget and the welcome-back offer

Add the Uppies widget to your home screen and it shows the next session — the week-and-day label and the lifts with their prescribed weights — updating whenever your data changes. On a shared device it names whose session it's showing.

And if life gets in the way for a week or more, Uppies notices: a Welcome back dialog offers to ease your working weights down before your next session, scaled to how long you were away. Weights only ever move down, declining is always an option, and normal progression resumes from whatever you choose. The tiers and fine print are in the FAQ.
