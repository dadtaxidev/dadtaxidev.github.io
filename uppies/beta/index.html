Uppies beta changelog

A running record of what changes in each beta release, newest first. Entries are grouped by type and ordered by impact.

Beta 4

Version 1.0 · Build 20260829.2212 · August 29, 2026

New features

  • New feature: Expanded Workout Together from two lifters to groups of up to four, while keeping each person’s workout, progression, history, totals, and rest timer separate.
  • New feature: Added an end-of-workout team summary with each participant’s completed volume and reps plus the combined team totals.
  • New feature: Added shared-workout history: completed sessions now remember and display who trained together.
  • New feature: Added all-profile team volume and rep totals to Progress for households that share one device.
  • New feature: Added an optional “Rotate lifters automatically” setting that hands the workout to the next person whenever a rest timer starts.

Updates

  • Update: Made Workout Together easier to discover with a dedicated toolbar button, a one-time invitation card, and expanded onboarding guidance.
  • Update: Added the automatic-lifter-rotation control to Settings as well as the Workout Together setup screen.

Bug fixes

  • Bug fix: Team summaries and all-time totals now convert mixed pound and kilogram profiles into one display unit before adding their volume.
  • Bug fix: Shared-session companion history now survives roster changes without losing earlier participants or producing unreadable saved data.
  • Bug fix: Improved active shared workouts when profiles are switched, renamed, or deleted elsewhere in the app.

Beta 3

Version 1.0 · Build 20260829.1714 · August 29, 2026

New features

  • New feature: Added a link to the official Greyskull LP book along with clearer program attribution.

Updates

  • Update: Expanded first-run guidance with an introduction to Greyskull LP, Phrak’s variant, the weekly lift rotation, working-set structure, AMRAP guidance, and progression rules before profile setup.
  • Update: Moved the starting-weight calculator and all per-exercise progression controls into a dedicated Exercise Settings screen, making the main Settings screen shorter and easier to scan.
  • Update: Added bar-weight configuration to the top of the onboarding starting-weights page.

Bug fixes

  • Bug fix: Onboarding pages now return to the top when moving forward or backward, so every step begins with its heading and introduction visible.

Beta 2

Version 1.0 · Build 20260828.2009 · August 28, 2026

New features

  • New feature: Added a configurable bar weight. Plate calculations, warm-ups, progression, and deloads now respect the bar you actually use and never prescribe less than its physical weight.
  • New feature: Added full-device backup and restore for profiles, workout history, and settings.
  • New feature: Added per-profile export and import, including the option to restore exported data as a new profile.
  • New feature: Added a welcome-back option after time away, with an easing-in reduction scaled to the length of the layoff.

Updates

  • Update: Starting-weight fields now focus automatically and select their existing value, so replacing a recommendation takes one step.

Bug fixes

  • Bug fix: An interrupted full-device restore can no longer leave profiles or their index out of sync.
  • Bug fix: Improved Workout Together reliability with stable participant controls during live countdowns, independent rest timers, and correct profile ownership when importing data.

Beta 1

Version 1.0 · Build 20260827.1325 · August 27, 2026

New features

  • New feature: Greyskull LP workout planning, set logging, automatic progression, warm-ups, and separate rest timers for warm-up and working sets.
  • New feature: Workout Together for two lifters sharing one device, with separate weights, histories, and timers.
  • New feature: Guided onboarding, optional profiles, and starting-weight setup.
  • New feature: Movement guides, workout history, progress charts, volume and rep totals, and a next-workout widget.
  • New feature: Local-only training data with no account, ads, or analytics.
  • New feature: Made Uppies available through TestFlight for its initial beta release.
