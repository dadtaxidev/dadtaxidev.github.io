TestFlight release notes

Uppies beta changelog

A running record of what changes in each beta release, newest first.

Beta 3

Version 1.0 · Build 20260829.1714 · August 29, 2026

  • Expanded first-run guidance with an introduction to Greyskull LP, Phrak’s variant, the weekly lift rotation, working-set structure, AMRAP guidance, and progression rules before profile setup.
  • Added bar-weight configuration to the top of the onboarding starting-weights page.
  • Onboarding pages now return to the top when moving forward or backward, so every step begins with its heading and introduction visible.
  • Moved the starting-weight calculator and all per-exercise progression controls into a dedicated Exercise Settings screen, making the main Settings screen shorter and easier to scan.
  • Added a link to the official Greyskull LP book along with clearer program attribution.

Beta 2

Version 1.0 · Build 20260828.2009 · August 28, 2026

  • Starting-weight fields now focus automatically and select their existing value, so replacing a recommendation takes one step.
  • Added a configurable bar weight. Plate calculations, warm-ups, progression, and deloads now respect the bar you actually use and never prescribe less than its physical weight.
  • Added a welcome-back option after time away, with an easing-in reduction scaled to the length of the layoff.
  • Added per-profile export and import, including the option to restore exported data as a new profile.
  • Added full-device backup and restore for profiles, workout history, and settings.
  • Improved backup reliability so an interrupted restore cannot leave profiles or their index out of sync.
  • Improved Workout Together reliability, including stable participant controls during live countdowns, independent rest timers, and correct profile ownership when importing data.

Beta 1

Version 1.0 · Build 20260827.1325 · August 27, 2026

  • Initial TestFlight beta.
  • Guided onboarding, optional profiles, and starting-weight setup.
  • Greyskull LP workout planning, set logging, automatic progression, warm-ups, and separate rest timers for warm-up and working sets.
  • Workout Together for two lifters sharing one device, with separate weights, histories, and timers.
  • Movement guides, workout history, progress charts, volume and rep totals, and a next-workout widget.
  • Local-only training data with no account, ads, or analytics.
